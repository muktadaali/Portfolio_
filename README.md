# Mohammed Muktada Ali — Portfolio Website

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation, project filters and active navigation
- `assets/profile.png` — supplied profile photo

## Run locally
Open `index.html` in a browser.

## Customize
1. Replace the demo project cards in `index.html` with your real project screenshots, names and URLs.
2. Update the skill percentages if you prefer not to display proficiency levels.
3. Change colors in `style.css` under `:root`.
4. Replace the email/WhatsApp/LinkedIn links if needed.

The portfolio content is based on the information supplied in your CV and conversation. Demo project cards are clearly presented as placeholders and should be replaced with your real work.
